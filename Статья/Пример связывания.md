# Пример связывания (пробный, удалить после проверки)

Символ DSSS состоит из 11 чипов [[IEEE Std 802.11-2020#^ieee-2765-7rnvvtj7|↗ стандарт]]. ^u0-1

Проверка: щелчок по «↗ стандарт» открывает абзац с цитатой в заметке стандарта, а оттуда «↗ PDF» — место в PDF в Zotero.
В заметке стандарта в панели «Обратные ссылки» должен появиться этот абзац.
