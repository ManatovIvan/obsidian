# Показание MTFI5CTD: Показание автора: во всех E-сессиях запускалась атака deauth; в E2 (Bruce) прошивка отработала некорректно — E2 исключить из обучения

Оригинал — [запись в Zotero](zotero://select/library/items/MTFI5CTD).

везде запускал deauth. Похоже, прошивка отработала криво. Значит эту сессию надо исключить из обучения ^t-mtfi5ctd-0

**Происхождение и пояснения:**

Источник: сообщение автора в сессии Claude Code 2026-10-12 (https://claude.ai/code/session_01D2gEwEtZbH7TnLruCtscax), ответ на вопрос Claude «E2 (Bruce): какую атаку запускали? В записи не найдено ни одного кадра ESP32 в DSSS». ^t-mtfi5ctd-2

Фиксируемые факты: (1) в сессиях E1, E2, E3 запускалась атака deauthentication; (2) в E2 прошивка Bruce, по мнению автора, отработала некорректно; (3) решение автора: сессию E2 исключить из обучения. ^t-mtfi5ctd-3

Статус: подтверждено автором. Примечание: «отработала криво» — интерпретация автора; наблюдение — отсутствие кадров ESP32 с верной FCS в E2 (коллекция 7). ^t-mtfi5ctd-4
