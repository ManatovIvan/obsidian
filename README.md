# Хранилище статьи «Обнаружение спуфинга 802.11 по RF-отпечатку» (ЦУОС 2026)

Здесь пишется текст статьи и хранятся связи «утверждение текста ↔ фрагмент источника».
Сами источники (PDF, выделения, показания, выводы запусков, код) хранятся в Zotero:
библиотека 22072154, коллекция «ЦУОС 2026 — RF fingerprinting». Zotero — источник правды
для родителей, это хранилище — для детей и связей.

## Где что лежит

**Zotero** хранит только оригиналы, без ссылок: PDF источников (с выделениями цитат), исходный код
`verification/*.py` с историей изменений, выводы запусков, показания автора (вопрос + ответ), экспорт
диалога claude.ai, утверждённую предрегистрацию. **Все связи и ссылки — только здесь.**

| Папка / файл | Что внутри | Кто пишет |
|---|---|---|
| `Статья/` | текст статьи, файл на раздел | вместе |
| `Источники/` | по заметке на источник: выделенные цитаты из PDF, у каждой — ↗ PDF и «используется в коде» | генерируется |
| `Доказательства/Код/` | код модулей; строка, к которой относится ссылка, — отдельный блок, под ним ↳ ссылки | генерируется |
| `Доказательства/Показания/`, `Выводы/`, `Расчёты/` | копии артефактов Zotero, каждая строка — блок с меткой | генерируется |
| `Результаты.md` | решения по H1–H4 со ссылками на строки выводов; факты, решения по правилу и наблюдения помечены | вручную |
| `Предрегистрация.md`, `Журнал отступлений.md` | документы, цитаты в них — ссылки на источники | генерируется |
| `_связи/код.json` | **источник правды для связей кода**: какая строка кода (по её тексту, без комментария) на что ссылается | правится при изменении связей |
| `Реестр.md` | сводка «утверждение статьи → родители» | собирается автоматически |

Всё, что «генерируется», строит `verification/obsidian_export.py` на сервере; руками не править.

## Как устроено связывание

**Родитель** — фрагмент, на который ссылаются: цитата из PDF, строка кода, строка вывода или показания.
Это абзац (или блок кода с абзацем ↳ под ним) с меткой блока в конце:

```
«The symbol duration shall be exactly 11 chips long.» — с. 2765 [↗ PDF](zotero://open-pdf/…) ^ieee-2765-7rnvvtj7
```

Ссылка `↗ PDF` открывает в Zotero место в PDF с выделенной цитатой.

**Ребёнок** — то, что опирается на родителя: строка кода или утверждение статьи. Утверждение статьи —
абзац с меткой и ссылками на родителей:

```
Символ DSSS состоит из 11 чипов [[IEEE Std 802.11-2020#^ieee-2765-7rnvvtj7|↗]]. ^u2-1
```

**Обратные ссылки** Obsidian показывает сам: у заметки источника в панели «Обратные ссылки» видно,
какие строки кода и утверждения статьи на неё опираются.

Правила меток:
- метка — латиница, цифры и дефис (ограничение Obsidian), в конце абзаца через пробел;
- утверждения статьи: `^u<раздел>-<номер>`, например `^u3-2`;
- метки фрагментов источников, кода, выводов и показаний выдаёт генератор, менять их нельзя.

Утверждение без ни одной ссылки на родителя — недопустимо. Такие места показывает `Реестр.md`.

## Синхронизация

Изменения идут через этот репозиторий GitHub: Claude отправляет с сервера, автор забирает на Mac
(удобно — плагин Obsidian Git) и наоборот. Чтобы не было конфликтов, один и тот же файл не правится
одновременно с двух сторон.

## Сборка в Word

В конце текст из `Статья/` собирается Pandoc в `.docx`; ссылки на литературу `[@ключ, с. N]`
превращаются в нумерованные ссылки и список литературы по ГОСТ. Для этого позже понадобятся
плагин Better BibTeX в Zotero и стиль CSL по ГОСТ.
