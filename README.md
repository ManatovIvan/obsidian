# Хранилище статьи «Обнаружение спуфинга 802.11 по RF-отпечатку» (ЦУОС 2026)

Здесь пишется текст статьи и хранятся связи «утверждение текста ↔ фрагмент источника».
Сами источники (PDF, выделения, показания, выводы запусков, код) хранятся в Zotero:
библиотека 22072154, коллекция «ЦУОС 2026 — RF fingerprinting». Zotero — источник правды
для родителей, это хранилище — для детей и связей.

## Папки

| Папка | Что внутри | Кто пишет |
|---|---|---|
| `Статья/` | текст статьи, файл на раздел | вместе |
| `Источники/` | по заметке на источник Zotero: выделенные цитаты, каждая — отдельный абзац с меткой | генерируется из Zotero |
| `Доказательства/` | выводы запусков, показания автора, фрагменты кода — тоже абзацами с метками | генерируется из Zotero |
| `Реестр.md` | сводка: какое утверждение на чём держится и что держится ни на чём | собирается автоматически |

Файлы в `Источники/` и `Доказательства/` руками не правятся: при следующей генерации правки
пропадут. Исправлять нужно запись в Zotero.

## Как устроено связывание

**Родитель** — фрагмент источника. Это абзац с меткой блока в конце:

```
«The symbol duration shall be exactly 11 chips long.» [↗ PDF, с. 2765](zotero://open-pdf/…) ^ieee-2765-chips
```

Ссылка `↗` открывает в Zotero место в PDF с выделенной цитатой.

**Ребёнок** — утверждение в тексте статьи. Это тоже абзац с меткой, а в нём ссылки на родителей:

```
Символ DSSS состоит из 11 чипов [[IEEE 802.11-2020#^ieee-2765-chips|↗]]. ^u2-1
```

**Обратные ссылки** Obsidian показывает сам: у заметки источника в панели «Обратные ссылки»
видно, какие утверждения статьи на неё ссылаются, вплоть до абзаца.

Правила меток:
- метка — латиница, цифры и дефис (ограничение Obsidian), в конце абзаца через пробел: `^u3-2`;
- утверждения статьи: `^u<раздел>-<номер>`, например `^u3-2`;
- фрагменты источников: `^<источник>-<страница>-<суть>`; их выдаёт генератор, менять нельзя.

Утверждение без ни одной ссылки на родителя — недопустимо. Такие места показывает `Реестр.md`.

## Синхронизация

Изменения идут через этот репозиторий GitHub: Claude отправляет с сервера, автор забирает на Mac
(удобно — плагин Obsidian Git) и наоборот. Чтобы не было конфликтов, один и тот же файл не правится
одновременно с двух сторон.

## Сборка в Word

В конце текст из `Статья/` собирается Pandoc в `.docx`; ссылки на литературу `[@ключ, с. N]`
превращаются в нумерованные ссылки и список литературы по ГОСТ. Для этого позже понадобятся
плагин Better BibTeX в Zotero и стиль CSL по ГОСТ.
